# 스마트스토어 자동화 프로젝트 — claude.md

## 프로젝트 개요

스마트스토어 계정 전환 및 퍼센티에서 크롬 확장 프로그램을 이용하여 복사 업로드 자동화 프로그램.

---

## 구조 — 4개 탭 릴레이

| 탭 | 역할 |
|---|---|
| 탭1 | 스마트스토어 로그인/로그아웃 전용 |
| 탭2 | 퍼센티 등록상품 관리 (셔플러 복사 실행) |
| 탭3 | 퍼센티 신규상품 관리 (옵티마이저 번호 삭제, 그룹 이동) |
| 탭4 | 퍼센티 신규상품 관리 (옵티마이저 업로드 실행) |

### 핵심 원칙
1. 각 단계 완료(로딩 끝, 팝업 출현 등)를 **캐치한 후에만** 다음 탭으로 전환
2. 엑셀 파일에서 계정 정보를 읽어서 순환

---

## 기술 스택

- **Chrome Extension Manifest V3** (정식 패키지)
- `chrome.scripting.executeScript` — 탭에 JS 직접 주입 (탭1 로그인)
- `chrome.debugger API` — 셔플러 확장 프로그램 제어 (탭2)
- `chrome.storage.local` — 계정 정보, 상태 공유
- `SheetJS (xlsx)` — 엑셀 계정 파일 파싱

## 탭1 — 스마트스토어 로그인/로그아웃

### 로그인 URL
```
https://accounts.commerce.naver.com/login?url=https%3A%2F%2Fsell.smartstore.naver.com%2F%23%2Flogin-callback
```

### 로그인 폼 선택자 (실제 확인값)
```javascript
input[type="text"]      // 아이디 입력란 (type=email 아님!)
input[type="password"]  // 비밀번호 입력란
// 로그인 버튼: button 중 textContent.trim() === '로그인'
```

### 핵심 구현 방식
- `chrome.scripting.executeScript`로 로그인 코드를 탭에 직접 주입
- content script 메시지 통신 X → 타이밍 문제 해결
- 탭 로드 완료(`chrome.tabs.onUpdated status=complete`) 후 2초 대기 → 스크립트 주입

### 입력 방식 (실제 동작 확인값)
```javascript
idEl.focus();
idEl.value = account.smartstore.id;
idEl.dispatchEvent(new Event('input',  { bubbles: true }));
idEl.dispatchEvent(new Event('change', { bubbles: true }));
idEl.dispatchEvent(new Event('blur',   { bubbles: true }));
await sleep(800);
// PW도 동일하게, 이후 1500ms 대기 후 버튼 클릭
```

### 완료 감지
- `location.href.includes('sell.smartstore.naver.com')` 감지 시 성공
- 성공 → background에 `TAB1_LOGIN_SUCCESS` 메시지 전송

### 주의사항
- `input[type="email"]` 선택자 사용 불가 (실제로는 `type="text"`)
- `button[type="submit"]` 없음 → 텍스트로 찾아야 함
- React SPA라서 입력 후 충분한 대기 필요 (각 단계 800~1500ms)
- 로그인 실패 시 자동 재시도 없이 중단 (무한루프 방지)

## 트러블슈팅 기록

### 1. Tampermonkey → Chrome Extension MV3 전환
- Tampermonkey가 페이지에서 `GM_setValue` undefined → 사이트 차단 문제
- **해결**: Chrome Extension MV3로 전환

### 2. content script 메시지 타이밍 문제
- background → content script 메시지가 페이지 로드 전에 도달
- 여러 방식 시도: `onUpdated`, `TAB1_READY`, storage 폴링, `onChanged`
- **해결**: `executeScript`로 로그인 코드를 탭에 직접 주입 (메시지 통신 제거)

### 3. 로그인 입력란 선택자
- `input[type="email"]` → null (없는 선택자)
- **실제**: `input[type="text"]` (alert으로 확인)

### 4. 로그인 버튼 클릭 안 됨
- `button[type="submit"]` → null
- **실제**: `Array.from(buttons).find(b => b.textContent.trim() === '로그인')`
- 입력 후 1500ms 대기 필요 (React 상태 반영)

### 5. 무한 새로고침 루프
- `TAB1_LOGIN_FAILED` → 자동 재시도 → 무한루프
- **해결**: 실패 시 자동화 완전 중단, 재시도 없음

### 6. 셔플러 외부 접근 차단
- `chrome-extension://` URL은 content script, 콘솔 접근 불가
- **해결 방향**: `chrome.debugger API` 사용
