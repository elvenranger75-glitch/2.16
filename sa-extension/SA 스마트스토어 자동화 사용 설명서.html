SA 스마트스토어 자동화 v2.14.0

스마트스토어 계정 전환 및 퍼센티 상품 복사·업로드 자동화 크롬 확장 프로그램 사용 설명서

1. 프로그램 개요

이 확장 프로그램은 여러 스마트스토어 계정의 퍼센티 상품 작업을 자동으로 처리합니다.
엑셀 파일에 계정 정보를 입력하면, 아래 4단계를 계정마다 자동 반복합니다.

탭1 — 스마트스토어 로그인
→
탭2 — 등록상품 복사(셔플러)
→
탭3 — 신규상품 이름수정·그룹이동
→
탭4 — 마켓 업로드
→
다음 계정 반복
탭작업 내용
탭1스마트스토어 로그인 / 2단계 이메일 인증 자동 처리 / 로그아웃
탭2퍼센티 등록상품 날짜 필터 → 상품 복사(그룹1로 이동)
탭3신규상품 이름에서 숫자 제거 → 그룹1 → 그룹2로 이동
탭4그룹2 상품 전체 네이버 마켓 업로드

2. 설치 방법

1 압축 파일 풀기

받은 SA_스마트스토어_자동화_v2.14.0.zip 파일을 원하는 폴더에 압축 해제합니다.

⚠ 폴더 위치는 이후 변경하지 마세요. 변경하면 확장 프로그램이 작동하지 않습니다.
2 크롬 확장 프로그램 개발자 모드 켜기
  1. 크롬 주소창에 chrome://extensions/ 입력 후 Enter
  2. 우측 상단 개발자 모드 토글을 켭니다 (파란색)
3 확장 프로그램 불러오기
  1. 압축 해제된 확장 프로그램 로드 버튼 클릭
  2. 압축 해제한 폴더(manifest.json이 있는 폴더) 선택
  3. SA 스마트스토어 자동화가 목록에 나타나면 설치 완료
4 사이드 패널 고정하기 (최초 1회)
  1. 크롬 우측 상단 퍼즐 아이콘(🧩) 클릭
  2. SA 스마트스토어 자동화 옆 핀 아이콘 클릭하여 고정
  3. 주소창 우측 로봇 아이콘(🤖)을 클릭하면 사이드 패널이 열립니다

3. 엑셀 계정 파일 작성 방법

폴더 안의 계정양식.xlsx 파일을 열어 아래 형식에 맞게 작성합니다.

A열B열C열D열E열F열G열
스마트스토어 ID 스마트스토어 PW 퍼센티 ID 퍼센티 PW 스토어명 (선택) 그룹1 그룹2
mystore123 password! percenty@email.com pw1234 나의 스토어 4번 5번
주의사항
• 1행은 컬럼 제목입니다. 2행부터 실제 계정을 입력하세요.
• B열(스마트스토어 PW)을 비워두면 브라우저 저장 비밀번호로 자동 로그인합니다.
• F열(그룹1): 탭2에서 복사된 상품이 도착하는 그룹 / 탭3에서 이름 수정 대상 그룹
• G열(그룹2): 탭3에서 이동할 목적 그룹 / 탭4에서 업로드할 그룹
• 그룹명은 퍼센티의 실제 그룹 이름과 정확히 일치해야 합니다 (예: "4번", "8번")

4. 사이드 패널 사용 방법

1 날짜 / 페이지 설정
설정설명기본값

셔플러 페이지탭2에서 처리할 페이지 수2
옵티마이저 페이지탭3 그룹 이동 반복 횟수 (페이지당 1회)2
실제 페이지 수가 설정값보다 적으면 실제 페이지 수 기준으로 자동 조정됩니다.
2 엑셀 파일 로드
  1. 📂 엑셀 파일 클릭하여 선택 영역 클릭
  2. 작성한 계정 엑셀 파일 선택
  3. 상태창에 "N개 계정 로드 완료" 표시되면 완료
3 자동화 시작
  1. 퍼센티(percenty.co.kr) 탭이 열려 있는지 확인합니다
  2. ▶ 시작 버튼 클릭
  3. 상태창과 로그에서 진행 현황을 확인합니다
4 버튼 기능

■ 정지즉시 자동화 중단
↺ 리셋모든 계정 상태를 '대기'로 초기화
⏸ 일시정지현재 단계 완료 후 일시 중지
▶ 재시작일시정지 해제 후 이어서 진행
복사실행 로그 전체를 클립보드에 복사

6. 2단계 인증(이메일) 자동 처리

스마트스토어 로그인 시 2단계 인증 (이메일로 인증) 화면이 나타나면 자동으로 처리합니다.

자동 처리 흐름
  1. "이메일로 인증" 섹션 확인
  2. 인증 버튼 클릭 → 네이버 메일로 인증 코드 발송
  3. 네이버 메일 탭 자동으로 열어 6자리 인증 코드 추출
  4. 코드 입력란에 자동 입력
  5. 확인 버튼 클릭 → 로그인 완료
인증 코드 메일이 오지 않거나 자동 처리에 실패하면,
3분 안에 수동으로 인증을 완료하면 자동화가 계속 진행됩니다.

7. 자주 묻는 질문 (FAQ)

퍼센티 탭이 자동으로 열리지 않아요
자동화 시작 전에 퍼센티(percenty.co.kr)에 미리 로그인된 탭을 열어두세요.
그룹 이름이 달라서 그룹 이동이 안 돼요
엑셀 F열/G열의 그룹명이 퍼센티 실제 그룹 이름과 정확히 같아야 합니다. 퍼센티 신규상품 페이지에서 그룹 탭의 이름을 복사해서 사용하세요.
업로드 수량이 복사 수량보다 적어요
로그 하단의 📊 수량 확인에서 어느 단계에서 누락됐는지 확인하세요. 그룹이동 수가 적으면 옵티마이저 페이지 수를 늘려보세요.
버전을 업데이트하려면 어떻게 하나요?
새 버전 zip 파일을 받아 같은 폴더에 덮어쓴 뒤, chrome://extensions/ 에서 새로고침(↺) 버튼을 클릭하세요.
자동화 중 오류가 발생했어요
로그의 빨간 [error] 메시지를 확인하세요. ↺ 리셋 후 다시 시작하거나, 해당 계정만 수동으로 처리 후 다음 계정부터 재시작할 수 있습니다.
중간에 멈추고 싶어요
⏸ 일시정지 버튼으로 현재 단계 완료 후 멈출 수 있습니다. ▶ 재시작으로 이어서 진행됩니다. 완전히 종료하려면 ■ 정지를 누르세요.

8. 주의사항 및 권장 환경

  • 브라우저: Google Chrome (최신 버전 권장)
  • 자동화 실행 중 퍼센티 탭을 닫거나 다른 사이트로 이동하지 마세요
  • 자동화 중 컴퓨터가 절전 모드로 전환되지 않도록 설정하세요
  • 여러 계정 처리 시 인터넷 연결이 안정적인 환경에서 사용하세요
  • 퍼센티 그룹 설정은 사전에 완료되어 있어야 합니다 (그룹1, 그룹2)
